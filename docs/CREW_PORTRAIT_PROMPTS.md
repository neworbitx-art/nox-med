# Crew portrait prompts

All 11 crew members are **fictional**. Photorealistic portraits cannot be produced inside this repository; generate them with an image model you are licensed to use (or commission them), then save each result as PNG 960x1200 at the path shown. Until a file exists the app shows the crew member's initials.

**Rules:** never use a real person's likeness (including real astronauts), no patches/logos/text, keep the same lighting and background for all portraits so they look like one set.

Shared style suffix:

> Photorealistic studio headshot, 85mm lens, f/4, soft even key light with gentle fill, neutral light-grey seamless background, plain navy flight suit collar visible, no mission patches, no text, no logos, natural skin texture with pores, sharp eyes, 4:5 portrait framing, head and shoulders, looking at camera.
